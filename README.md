# RunnyBunny

RunnyBunny is a mobile-first React prototype for a quiet running diary app built around a companion Bunny character.

## Features

- Home dashboard with Bunny condition, cumulative distance, and next level progress
- Running record screen with camera-style media upload and short notes
- Friend-only feed with emoji encouragement instead of comments
- Memory timeline with a "1 year ago today" card
- Bunny profile with level, condition, total distance, total runs, and streak

## Tech

- React
- Vite
- Mock data only, no backend yet

## Run Locally

```bash
npm install
npm run dev
```
